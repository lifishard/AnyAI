## 依次施工

- [x] 1. 观测模型：任务、执行阶段、事件、验收状态和用户反馈分别定义；区分事实/估算/未知。定义版本、白名单和数据边界。
- [x] 2. 本地记录：接入任务开始、等待、暂停、恢复、要求/验证、请求/工具/压缩和交付；持久化、去重、重启恢复、缺口提示；统计失败不影响任务本身。
- [x] 3. 反馈与查看：可选用户结果反馈；按时间、模型、版本筛选，展示实际状态和记录来源；不输出综合健康分或无依据的成功率。
- [x] 4. 导出：使用分析包（report.md、tasks.jsonl、events.jsonl、manifest.json）；指定任务排查包；可选择并预览必要片段，默认不含正文/路径/凭据/思考内容。
- [x] 5. 生命周期：90 天/500 个任务/4MB 索引/每任务最多 200 个事件的有界统计保留；裁剪留下缺口计数；删除对话清除关联统计，支持单独清空统计、稳定导出标识与重置说明。
- [x] 6. 验证：验收→修复→交付、暂停→补充→继续、未知外部结果；统计去重与口径、缺失/旧数据、筛选、脱敏、导出包可解析；桌面和窄屏、原生完整流程。
- [x] 7. 交付：更新版本与文档，运行构建和项目检查，独立打包并核实包内文件；保留原有安装包，不自动安装或发布。

## 关键验收标准

证据存在不等于要求满足；程序结束不等于验收通过或用户确认。未反馈/未继续/缺失用量不补零。统计能够关联任务排查，数字携带分母、观察期、来源和限制。正常恢复不重复执行已完成副作用，不重复累计任务。统计导出默认不包含正文、原始错误、路径、完整接口地址或凭据。
