# AnyAI 1.2.0 施工路线图

总设计见 [计划书](ADAPTIVE_CONTEXT_PLAN.md)。按依赖顺序推进，只有完成代码与相应验证才勾选。

- [x] 0. 固化讨论：范围、研究依据、适配原则、里程碑、占用圆圈、RSI 边界和验收。
- [x] 1. 路由能力与用量：定义版本化能力档案，严格学习上限，输出/思考预留，估算校准，未知状态。
- [x] 2. 额度调度：共享组、分维度额度、响应头剩余/恢复、取消、错误分类和实际用量结算。
- [x] 3. 持久任务状态：里程碑更新与证据，目标/进度独立保存，重启和切模型继续。
- [x] 4. 多策略上下文：本地折叠、语义摘要、原文按需读取、校验与原子替换、连续多次压缩。
- [x] 5. Agent 接入：每轮预算和调度，摘要独立计费/取消，任务完成条件，继续与暂停语义。
- [x] 6. 用户界面：能力设置、里程碑与划掉状态、占用圆圈及明细、窗口/工作预算/分钟额度分开。
- [x] 7. 自动与渲染验证：窗口/思考/额度矩阵，摘要失败与恢复，桌面/窄屏，原生隔离执行。
- [x] 8. 交付：更新架构与配置文档，检查构建，独立版本打包，写明验证结果与未验证范围。

## 施工约束

保留当前未提交的 1.1.1 修复和用户变更。任何计划调整在这里记录原因和影响。没有用户明确要求，不推送、不发布、不自动安装。供应商原生协议/原生压缩和 RSI 自动优化属于扩展阶段，本轮完成通用兼容接口上的上下文管理。

## 执行记录

- 2026-09-13：检查现有实现。主要缺口为模型名驱动的思考映射、固定工作预算、单一 token 额度、缺少正式里程碑与语义压缩状态。已有执行日志、真实产物索引和恢复机制作为基础保留。

## 最终验收记录

- 自动回归：31 项，通过窗口/思考/额度矩阵、三次增量压缩、原文取回、摘要无效与取消、里程碑证据、限定引用检索范围、停止和切模型恢复。
- 界面：1440×1050 与 430×932；窗口未知、填写能力、输入变化、切模型、里程碑划掉与展开证据、等待状态清除、刷新后保留；页面与控制台检查通过。Browser 插件未提供，使用现有 Playwright 与隔离 Edge。
- 原生桌面：独立 userData 与本地模拟接口；实际 ICS 写入和路径核实、里程碑更新、连续三次语义压缩、完整工作记录保留、摘要交换记录与完成状态经刷新/关闭后保留；流式超时、取消、429 原文与 Retry-After 验证通过。
- 没有使用真实供应商密钥、没有请求真实 Canvas 数据；上述通过不代表已实测所有供应商模型的摘要质量或完成率。
- 最终检查：31 项自动回归、类型检查、50 个文件的项目检查、Vite 生产构建、最终构建的桌面/窄屏与原生复验均通过。安装包内版本为 1.2.0，构建资源与关键原生文件和已验证版本一致。
- Windows 交付：`release/1.2.0/AnyAI-1.2.0-win-x64-setup.exe` 与 `release/1.2.0/AnyAI-1.2.0-win-x64-portable.exe`。保留旧版，未自动安装、关闭旧应用、推送或发布。

## 落地说明

- 未知窗口采用 24K 工作预算；已知窗口的自动工作目标最高 96K，允许手动调整。这是可见的初始策略，不宣称是普遍最佳阈值。
- 大型文本附件可外置并分页取回；较早图片可按消息 ID 和图片序号取回。原始用户指令保留，引用限定范围也约束检索工具。
- 能力观察按字段分别失效，估算按路由/思考/图片与文本校准。摘要请求的来源范围、用量、耗时、取消或未通过校验原因有独立记录。
- 保留跨协议扩展和 RSI 自动学习为后续范围，本轮没有静默调用另一家摘要模型或改变所选思考档位。
