# 2.1.0 — 本机连接与提问卡片

普通对话的模型选择器新增“本机 AI”，可检测官方 Codex、Claude Code 和 Kimi Code 客户端，选择其提供的模型与思考强度。Codex 在官方浏览器页面完成 ChatGPT 登录；wickrunAI 不接收登录凭据。Claude 和 Kimi 使用本机官方客户端已有授权。Grok 和其他兼容服务使用原有 API 配置。

连接器随开源桌面版分发，在每个用户自己的电脑上运行。程序位置根据用户环境检测，也可手动选择原生程序。没有捆绑特定账号、固定用户目录或中转服务器。完整实现边界见 [本机连接说明](../LOCAL_CONNECTIONS.md)。

Chat 和 Work 都可展示结构化提问卡片，包含一到三个问题、选择项与自由输入。没有默认替用户作答。问题草稿、提交答案及执行游标独立留档；收到回答后继续当前任务。权限审批仍是另一条流程。

原生请求在派发前写入执行记录，返回结果单独保存。重启后恢复已完成的结果，不自动重跑结果尚未确认的操作。本机连接携带原对话、文本附件和任务交接记录；图片暂需要支持图片的 API 连接处理。

验证结果：203 项自动测试全部通过；在临时目录通过链接访问的环境下，全套测试也通过。类型检查和正式前端构建通过。界面验证覆盖连接切换、模型和强度选择、提问作答，以及真实桌面接口下的问题草稿重启恢复。未使用真实订阅账号进行模型调用；不同官方客户端版本和账号的实际可用能力仍需对应环境验证。

修复了 [2.0.1 发布任务](https://github.com/lifishard/wickrunAI/actions/runs/34789227334) 中的跨平台测试路径问题：Windows 的故障注入使用了未规范化路径，未能触发预定的崩溃；macOS 的临时目录 `/var` 别名导致清理检查及文件隔离测试失败。测试现在使用临时目录的真实路径，文件故障注入与保存的项目路径保持一致。原有的目录身份与符号链接保护检查保留。使用路径大小写差异和临时目录链接分别重现了旧版失败，修正后两组均通过。
