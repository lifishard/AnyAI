# wickrunAI 1.3.3 · 灯芯AI

应用由 AnyAI 更名为 wickrunAI，中文名为灯芯AI。

- 更新应用标题、快捷方式、安装包名称和 GitHub 仓库链接。
- 继续使用旧版数据目录和加密身份，保留已有配置、会话、任务记录和工具浏览器资料。
- 修复输入框弹层被裁切的问题，包含此前未发布的 1.3.2 界面修复。
- 重写 README，补充安装、模型接力和升级说明。

## 下载

| 平台 | 文件 |
|---|---|
| Windows 64 位 | `wickrunAI-1.3.3-win-x64-setup.exe` 或 `wickrunAI-1.3.3-win-x64-portable.exe` |
| macOS Apple Silicon | `wickrunAI-1.3.3-mac-arm64.dmg`，另有 ZIP |
| macOS Intel | `wickrunAI-1.3.3-mac-x64.dmg`，另有 ZIP |
| Linux 64 位 | `wickrunAI-1.3.3-linux-x64.AppImage` 或 `.deb` |

安装新版前请退出旧版。安装包没有代码签名。可用 `SHA256SUMS.txt` 核对下载文件。

## 数据兼容

桌面端继续使用 `AnyAI` 数据目录及原安装标识。名称保留是为了读取旧版配置、任务检查点、浏览器资料和加密凭据。macOS 与 Linux 的系统密钥环可能要求重新授权；这次发布不包含这两个系统上的人工升级验证。
