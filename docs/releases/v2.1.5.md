# 2.1.5 — Claude Desktop 主脑协作

本机 AI 面板中的 Claude Desktop 现在提供可调用的 MCP 接口。点击“一键配置并打开”添加连接，首次完全退出并重新打开 Claude Desktop 后，在连接器中启用 `wickrun_ai`。

在“任务与结果”中输入目标，选择 API 工作模型及最多调用次数。创建任务会打开 Claude Desktop 并预填任务交接消息；用户在官方应用中发送并授权工具后，Claude 可以拆解任务、委派工作模型、读取结果、报告进度并交回最终成果。账号登录仍由官方应用完成。

每个任务固定工作模型与 API 来源，最多同时执行两个子任务。派发前保存记录，重复请求键不会重复发送；取消、失败及应用中断均不会自动重发。结果可在任务记录中查看、复制、保存。工作模型本轮提供文字结果，不开放文件或命令执行。

界面分别显示配置完成、实际 MCP 连接、主脑处理进度和最终成果回传。ChatGPT · Codex 继续使用现有连接。

验证：247 项测试通过；生产构建通过；真实 stdio MCP 与隔离 Electron 主进程的任务往返，以及桌面/窄屏界面已验证。账号登录及真实 Claude Desktop 模型执行需在用户客户端完成，不属于离线测试结果。
