# 2.1.1 — 长任务上下文续跑

长任务接近上下文上限时，不再按旧的 24K 阈值硬暂停。旧阈值迁移为 1M 上限建议；默认阶段 token 预算为 `0`，表示不限制阶段预算。1M 作为提醒和建议使用，不会把任务强制停下。

右侧上下文区域提供可选的临近上限提醒和自动交接设置，默认关闭。接近 90% 时可以生成新对话草稿并预填接续内容；这一步只准备草稿，不自动调用模型，也不会停止原任务。

需要继续时，用户可以手动压缩后续跑，或手动在新对话中交接。原任务、压缩边界和交接草稿都按用户操作推进，避免在上下文接近上限时丢失工作控制权。

温度默认不勾选，请求不再自动携带 `temperature: 0.8`，由模型服务采用自身默认值；旧版默认勾选也会迁移。需要精细控制时，仍可按需启用并填写自定义 `temperature`。
