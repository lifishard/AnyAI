# wickrunAI 2.0.0

新增项目协作空间，将成员配置、任务讨论、工作流、文件和交付验收放在同一项目中。

- 单一 Agent / 协作空间入口与 Chat / Work 切换。
- 工作流自由画布、分支、有限循环、撤销重做、列表编辑和不可变运行版本。
- 多成员执行、并行汇合、结构化质检、人工验收、总预算与检查点恢复。
- 成员隔离文件副本、精确差异合并、冲突检查和中断恢复。
- 本地草稿与历史持续保留；数据损坏时停止写入并提供备份恢复。
- 配置模板、完整归档导出、每日定时任务与项目经验记录。
- 官方 Codex 本机协议和 Claude Code 原生程序适配。

从 1.x 更新继续沿用原用户数据目录。安装包不会用示例配置替换用户项目。

订阅连接需要用户在官方客户端登录，真实账号调用效果仍待试用。原生客户端权限不能完全对应 API 的逐工具白名单。协作定时任务需要应用保持打开；讨论节点当前按成员顺序执行；项目经验采用由用户决定，自动 RSI 实验尚未实现。

Windows 源码使用者可依次双击“打包桌面版.bat”“同步到github.bat”“发布三平台版本.bat”。第一个成功后打开安装向导；第三个触发 GitHub Actions，三平台全部构建并核验成功后公开 Release。
