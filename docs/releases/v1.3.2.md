# AnyAI 1.3.2

修复输入区胶囊菜单撑出可用空间、顶部被裁切的问题。

- 模型选择、上下文用量、思考强度、附件和操作确认菜单统一按可见窗口定位，自动选择上下展开方向，避开顶部栏。
- 弹层独立于聊天滚动区域；窗口缩小、位置变化时重新调整，空间不足时可滚动阅读全部内容。
- 模型列表可缩短；凭据很多或展开异常模型时，完整面板仍可滚动到首尾。
- 窄屏输入栏自动换行，保留思考和发送按钮；支持点击外部关闭、Escape 关闭并返回触发按钮。
- 修复发布时 Linux 架构文件名不一致的问题，更新 GitHub Actions 组件以使用 Node 24 运行时。
