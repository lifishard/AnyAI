# AnyAI 1.3.1

同一份任务记录支持多模型接力：保留用户要求、总结记忆、原始证据和待办，切换模型后按新模型的上下文窗口重新计算预算。暂停任务可以切换模型后继续执行，同窗口追问也会承接交接记录。

- 改善任务完成后的产物展示、验收和继续修改流程。
- 完善上下文交接记录与来源读取，保留恢复位置和执行统计。
- 修复本地打包流程，按版本保存安装包，并清理更旧的已识别产物。
- 新增“发布三平台版本.bat”，三平台构建和安装包检查全部成功后统一公开发布。

## 下载选择

| 系统 | 文件 |
|---|---|
| Windows 64 位 | `AnyAI-1.3.1-win-x64-setup.exe`；免安装可选 `AnyAI-1.3.1-win-x64-portable.exe` |
| macOS Apple Silicon | `AnyAI-1.3.1-mac-arm64.dmg`，另有 ZIP |
| macOS Intel | `AnyAI-1.3.1-mac-x64.dmg`，另有 ZIP |
| Linux 64 位 | `AnyAI-1.3.1-linux-x64.AppImage` 或 `.deb` |

`SHA256SUMS.txt` 提供校验值，`release-manifest.json` 记录构建源码和文件信息。

这些安装包未做代码签名；安装说明见 README。Windows 已完成本地桌面交互验证；macOS 和 Linux 由各平台 Actions 构建，未做实体设备交互验证。模型接力表示应用已准备或发送交接上下文，不保证模型正确理解，最终结果仍需验收。
