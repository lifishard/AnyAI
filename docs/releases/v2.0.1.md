# 灯芯AI 2.0.1

单一 Agent 与协作空间现在共用侧栏框架。品牌、当前项目、工作区切换胶囊固定在同一位置，切换时保持侧栏宽度；页面顶栏、字号、按钮、选中状态和窄窗口导航使用一致样式。

Chat / Work 控件的蓝色选中背景改为完整圆角胶囊，并与外框保留间距。

切换 Chat / Work 继续使用同一对话，保留历史消息、附件、项目规则和保存的执行上下文。发送时固定该条消息的模式；排队消息不受后续模式选择影响。在 Chat 生成中切到 Work，当前回复继续完成，下一条消息携带最新上下文交给 Work。切换本身不会自动发起新的任务。

工作区切换保留聊天草稿；两个工作区分别记住自己的项目上下文，浏览协作项目不会重新归属当前聊天。

验证覆盖 Chat → Work 真实请求组装、排队交接、桌面与窄窗口切换、深色主题，以及现有执行和发布回归测试。界面测试使用隔离测试数据和模拟模型响应，不调用用户账号。

安装更新会沿用原有用户数据目录。继续使用三个批处理入口打包安装、同步代码和触发三平台发布。
